# Contributing to NowcastBox projects

Thank you for your interest in contributing! Each repository has its own detailed guide;
for the library see
[nowcastbox/CONTRIBUTING.md](https://github.com/NowcastBox/nowcastbox/blob/main/CONTRIBUTING.md).

In short:

1. Open an issue first for larger changes, so the approach can be discussed.
2. Work on a feature branch (`feat/<topic>`, `fix/<topic>`) and open a pull request
   against `main`.
3. Every change comes with tests and documentation; the CI quality gates (tests,
   coverage, ruff, pyright, docs build) must pass.
4. Pull requests need one approving review from a maintainer.

By contributing you agree that your contributions are licensed under the repository's
license (MIT for `nowcastbox`) and you follow our [Code of Conduct](CODE_OF_CONDUCT.md).
