# Security policy

Please report security vulnerabilities **privately**, not in public issues, using
GitHub's [private vulnerability reporting](https://github.com/NowcastBox/nowcastbox/security/advisories/new)
on the affected repository, or by e-mail to gustavo.haase@gmail.com.

We aim to acknowledge reports within 7 days. Security fixes are released for the latest
minor version of `nowcastbox`.
